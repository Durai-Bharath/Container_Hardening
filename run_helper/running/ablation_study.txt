Run these six commands from the repository root.

### 1. Frequency + Sustained

```bash
python3 -m running_phase_ablation.main \
  --running-trace traces/nginx_test_discovery_trace.jsonl \
  --output nginx_frequency_sustained_report.json \
  --feature-mode frequency \
  --segmentation-mode sustained \
  --window-seconds 0.001 \
  --similarity-threshold 0.8 \
  --stabilization-seconds 5
```

Profiles are generated automatically under:

```text
running-seccomp-ablation/
├── frequency/
│   ├── sustained/
│   └── first/
├── bigram/
│   ├── sustained/
│   └── first/
└── combined/
    ├── sustained/
    └── first/
```

Each report contains the segmentation point, similarity values, running syscall set, feature vocabularies, windows, and generated profile path.
